Amara · custom thematic icon set

"Cute ghost icons for each tab" — a worked example

A generic open-source icon library (Lucide, used for this system's ordinary UI icons) has no "cute ghost" glyph — that's a thematic/character request, mapped to iconography.customMotif instead of setReference. These three icons are original, hand-authored SVG paths (one shared ghost silhouette, distinguished per tab by a small functional badge) — not sourced from anywhere, so there's no license to get wrong. customMotif.authorship: "hand-authored-original" in theme.json.
