What this demonstrates: per meta.removedElement, the first draft embossed every message bubble along with the send button — a whole thread of soft-shadowed surfaces reads as texture, not distinguishable messages, and pushes text contrast toward exactly the failure the accessibility flag warns about. This version keeps the tactile cue to one control (the send button, visible dual-shadow emboss) while every message bubble is flat with a hairline border and full-contrast text (10.95:1 body, 5.76:1 secondary — see theme.json's a11y.contrastReport, including two colors that failed on a first pass and were darkened before shipping).
